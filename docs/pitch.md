# 시켜용: 마루 대표 레퍼런스 디앱 (한 장 요약)

2026-11-18 · 호재 · 재욱 님 설명용

**AI 비서가 카드번호 대신 한도가 걸린 원화(OKRW)로 배달을 시켜 주고, 그 한도와 신원 확인은 앱이 아니라 마루 체인이 지킨다.**

## 왜 만드나

- 한국 AI 비서는 이미 돈을 쓴다. 앱스토어 상위권인 AI 비서 피클은 카드번호를 폰 금고에 넣어 결제하고, AI가 요청을 오해해 식당 여러 곳에 전화를 거는 일도 있었다. AI가 실수하면 카드 한도까지 쓸 수 있는 구조다.
- 한국 생활 에이전트 스킬 모음 k-skill(스킬 125개, GitHub 스타 7.7k)은 조회와 예약까지만 하고 결제에서 멈춘다.
- AI 에이전트 결제의 약 98.6%가 달러 스테이블코인이다. 원화로, 그리고 "이 AI가 누구의 대리인인지"를 보장하는 결제는 아직 없다.
- 대표님이 말해 온 에이전트 화폐의 조건(신원, 권한 위임, 지출 한도, 킬 스위치)을 제품 하나로 보여 줄 수 있다.

## 무엇을 만드나 (첫 버전: 배달 관리 AI 비서)

마스코트는 알에 반쯤 걸쳐 앉은 아기 드래곤. 이름 "시켜용"은 "시켜요"와 "용"을 합쳤다.

- **알아서 시켜 줌**: "점심 시켜 줘" → 날씨, 위치, 이번 달 예산을 보고 추천 → 원화로 결제 → 주문 완료
- **잔소리**: "이번 달 배달비 21만 원 썼어용, 주말엔 집밥 어때용?" (예산의 70%부터)
- **내가 정하는 한도**: 한 번에 쓸 돈(5천~5만 원)과 30일에 쓸 돈을 사용자가 정한다. 한 번에 쓸 돈은 체인이 지킨다. 한도를 키울수록 드래곤이 자란다 (D-31).
- **킬 스위치**: 주인이 언제든 정지하고 남은 용돈을 회수한다.

## 왜 꼭 마루인가 (Base + USDC로 옮기면 깨지는 것)

| 장면 | 마루가 하는 일 |
| --- | --- |
| 원화 결제 | OKRW로 결제하고 가스도 원화(또는 페이마스터) |
| 체인이 지키는 한도 | AI가 속거나 앱이 뚫려도 주문은 건당·30일 한도를 못 넘는다. 앱이 아니라 체인(PCL)이 거절한다 |
| AI 신분증 | ERC-8004 등록 + 주인 KYC. 가게는 따로 확인하지 않아도 된다 |
| 규칙 변경 즉시 적용 | 정책값을 바꾸면 앱을 다시 배포하지 않아도 바로 적용된다 |
| 빼돌리기 방지 | AI 지갑에는 주문 한두 번 분량만 두고 주문 직전에 채운다. AI가 새 지갑으로 빼돌려도 그 소액뿐이다 |

정상 흐름에서도 보이게, 영수증에 "마루 규칙 5개를 통과했어용"을 띄운다.

## 데모 하이라이트 (약 5분)

같은 "지갑 키 유출" 상황을 나란히 보여 준다. 기존 에이전트 결제 스킬은 한도를 지갑 프로그램이 지켜서 잔액이 다 빠진다. 시켜용은 주문 경로의 큰돈은 체인이 막고, 직접 송금으로는 지갑에 둔 소액만 나간다. "체인이 다 막는다"고 과장하지 않고 정직하게 보여 준다.

## 범위와 일정

- **12/9까지**: 모바일 화면 웹 데모, 목 가게 8곳(1곳은 미인증 가짜 가게), 테스트넷. 웹은 Next.js, 백엔드는 NestJS로 만든다.
- **2단계**: iOS 출시(회사 조직 계정 필요), 실제 가게 등록(국세청 사업자 확인 + KYB), VP로 배달 내역 비공개.
