# 문체

## 최우선
- **em dash(U+2014)와 en dash(U+2013)를 쓰지 않는다.** 문서, 주석, 커밋, UI, 영어 글 모두. 대신 마침표, 쉼표, 콜론(:), 괄호로 끊는다. 범위는 "11/18~11/23" 또는 "11/18부터 11/23까지".
- 검사: `pnpm check:dash` (또는 `grep -rnP '\x{2014}|\x{2013}' --exclude-dir=node_modules .`).

## 사실 표시
- (확인): 문서·코드·실행으로 확인함. 가능하면 출처(docs.maroo.io 경로, 파일, 트랜잭션 해시)를 붙인다.
- (추론): 확인한 사실에서 해석함.
- (미확인): 모름. `log/open-questions.md`에 올린다.
- (확인 필요: 누구): 담당이 있는 미확인.

## 문장
- 한 문장 25자~40자 안팎, 길어도 한 줄 반. 문단은 3문장 이하.
- 결론을 먼저. 문서와 절의 첫 문장이 요점이다.
- 형용사보다 숫자와 이름 ("한도가 낮다"가 아니라 "건당 10,000 OKRW").
- 병렬 항목만 불릿, 순서가 있으면 번호 목록, 여러 속성 비교는 표.
- 같은 내용을 두 문서에 쓰지 않는다. 한 곳에 쓰고 링크한다 (스펙은 tech-spec, 규칙은 위키, 결정은 decisions).

## UI 문구
- `product/mascot-and-voice.md`를 따른다.
- 기술 용어(revert, PCL, aokrw)는 상세 화면에서만. 기본 문구는 쉬운 말.

## 마루 관련 표현
- "체인이 막는다"는 PCL이 실제로 막는 경우에만 쓴다. MAWS나 서버가 막는 것은 "앱이 막는다" 또는 "비서가 멈춘다"로 구분한다 (데모의 핵심 구분).
- 공개 자료에 쓰지 않은 마루 일정(메인넷 등)은 쓰지 않는다.
