# PastLine

`packages/ui/src/chat/PastLine/`

## 책임
지난 대화의 추천, 견적, 주문 카드를 버튼 없는 한 줄 요약("돼지국밥 9,000원, 도착함")으로 그린다 (D-34).

## 책임 아님
요약 문장 만들기와 주문 상태 읽기 (웹 대화 기능이 글로 넘긴다)

## props
`text: string`

## 하네스 상태
`PastLine.stories.tsx`에 아래를 전부 만든다.
- 도착한 주문 (`Arrived`)
- 고르지 않은 추천 (`Unpicked`)
- 긴 글 (`Long`, 한 줄에서 줄임표)

## 쓰는 화면
Main (접힌 지난 대화)

## 테스트 기준
- 글만 그리고 누를 수 있는 것(버튼, 링크, 탭 가능)이 하나도 없다. 지난 견적으로는 결제할 수 없다 (규칙 3과 9)
- 한 줄(`nowrap`)에 줄임표, `ink-muted`와 `type.stamp`

## 메모
- 시안에는 아직 없다. 디자이너 확인 필요 (디자인 공백): 접힌 한 줄의 모양(아이콘, 칩 여부). 지금은 글자만 둔다.
- 움직임 없음. 지난 대화는 정지한 기록이다 (D-23은 지금 대화에 쓴다).
