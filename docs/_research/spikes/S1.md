# S1 MAWS가 컨트랙트 함수를 호출하나 (2026-11-20)

- 질문: 에이전트가 MAWS로 `SikyeoyongOrders.placeOrder`처럼 컨트랙트 함수를 부를 수 있나 (D-05 경로 A의 조건, Q-01).
- 범위: 호재 님 승인으로 **도구 스키마만 읽었다**. MAWS 도구는 하나도 호출하지 않았다 (faucet, 에이전트 생성, 송금 없음).
- 출처: 이 세션에 연결된 m-aws MCP 서버의 도구 정의 (Claude Code 도구 목록, 2026-11-20).

## 결과
`transfer_send` 입력 스키마 (발췌, 원문 그대로):

```json
{
  "additionalProperties": false,
  "properties": {
    "agentId": { "type": "string", "description": "The agent's UUID (from `agent.list`)" },
    "amount": { "type": "string", "description": "OKRW amount as a decimal string (e.g. '50' or '0.25')" },
    "clientToken": { "type": "string" },
    "to": { "type": "string", "description": "Destination EVM address (0x-prefixed 40 hex chars)" }
  },
  "required": ["agentId", "to", "amount"]
}
```

- calldata(`data`) 칸이 없고 `additionalProperties: false`라 다른 칸도 받지 않는다 (확인). MCP로는 컨트랙트 함수를 부를 수 없다.
- 같은 도구 설명 첫 문단 (원문): "Before submitting, this MCP server (m-aws) checks the agent's on-chain policy (spending limit + allowed targets); WaaS does not enforce that policy itself. The transaction is signed by WaaS on the agent's behalf." (확인)
- `policy_set`, `policy_preflight`, `agent_create`, `agent_fund`, `agent_freeze`, `agent_detail`, `transfer_initiate` 스키마에도 calldata를 받는 칸은 없다 (확인).
- WaaS API를 MCP 없이 직접 부를 때 calldata를 받는지는 문서와 도구 어디에도 없다 (미확인, Q-01 계속).
